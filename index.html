Students and families

Add students with grade, village, school and contact details. IDs are created for you, like 26BEG001. Search, filter and bulk edit in seconds.

Teachers mark attendance only inside the daily window you set. Rain day? Stop the window with a reason, then resume it tomorrow.

Questions

Quick answers

Do we need to install anything?

No. It runs in any modern browser on desktop and mobile. You only need an internet connection.

What if a teacher misses the attendance window?

Only admins can submit outside the window. The admin enters the attendance on the teacher's behalf for any date and class.

Can we fix a mistake after attendance is submitted?

Admins can edit any record. Each change is logged with the editor's name, the time and a reason.

Can we run more than one VBS year?

Yes. Each year has its own students, classes and reports. Switch years from the selector at the top of the dashboard; the active year is marked Live.

How do we keep a record of the programme?

Export the full-year PDF at the end of the programme. You can choose which sections to include, such as student lists, class grids and teacher records.
